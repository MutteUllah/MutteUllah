## Selected projects

### [Video Action Recognition / CrimeVision-Net](https://github.com/MutteUllah/video-action-recognition)

A Python video-analysis project combining YOLO11 detection, ByteTrack tracking, temporal clip buffers, and VideoMAE classification. Includes training utilities, alert stabilization, and a Streamlit interface for uploaded videos.

**Built with:** Python · PyTorch · Hugging Face Transformers · Ultralytics · OpenCV · Streamlit

### [SupportDesk AI](https://github.com/MutteUllah/supportdesk-ai)

A multi-tenant customer support application with document ingestion, cited retrieval, an embeddable chat widget, support tickets, and human handoff. The local implementation includes a FastAPI backend, a Next.js dashboard, and background processing with Celery.

**Built with:** Python · FastAPI · LangGraph · PostgreSQL/pgvector · Redis · Celery · Next.js · React · TypeScript

The repository includes Docker setup, architecture documentation, screenshots, and automated checks. The default demo uses deterministic mock retrieval and extraction; an OpenAI-compatible provider can be configured separately. Local verification passed 27 backend tests and the browser acceptance flow. Infrastructure and real-model checks have separate scope in the verification record.

### [LangGraph Agent Patterns](https://github.com/MutteUllah/langgraph-agent-patterns)

Two educational examples covering supervisor routing, planning and tool loops, SQLite checkpoints, and semantic memory. Includes offline tests with fake model responses; search, email, and account tools are explicitly simulated.

**Built with:** Python · LangGraph · LangChain · Gemini integration · SQLite
